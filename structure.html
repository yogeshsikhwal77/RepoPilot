RepoPilot v4.1

Upgrade focus: prove it with numbers (evaluation first), make the core algorithms visible (AST, call graph, hybrid search, graph traversal), harden the sandbox and verifier, and make cost control a measured feature. Memory stays a stretch goal; Kubernetes, Terraform, Grafana, LSP and the VS Code extension stay cut.
